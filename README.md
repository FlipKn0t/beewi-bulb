# BeeWi SmartLite Bluetooth controller

A single-page web app that controls a BeeWi SmartLite bulb directly over Bluetooth LE
(power, brightness, warm/cool white, colour wheel, saved colours, cycle/fade/strobe/flicker effects).

Open it at https://flipkn0t.github.io/beewi-bulb/ in a browser with Web Bluetooth:
Chrome on Android/desktop, or the **Bluefy** app on iPhone.
